## Безопасность

**2026-09-26 — Пароли тестовых учёток не хранятся в коде.** Репозиторий был публичным, а в README
были логины и пароли seed; пароль администратора из README подходил к боевой админке. Пароль
администратора на сервере сменён, репозиторий переведён в приватный. Seed берёт пароли из
`SEED_ADMIN_PASSWORD` / `SEED_TEACHER_PASSWORD` / `SEED_CLIENT_PASSWORD` или генерирует случайные.
Форма создания педагога больше не подставляет пароль по умолчанию.

**2026-09-26 — Никаких секретов в репозитории.** Пароли, токены ботов, ключи API — только в `.env`
на сервере (файл в .gitignore). Перед тем как сделать репозиторий публичным — проверить историю
на секреты. В старых коммитах остался прежний пароль администратора — при случае вычистить историю.

**2026-09-26 — Вход администратора через MAX требует реального телефона в учётке.** Сейчас у
администратора телефон-заглушка из seed, поэтому вход по коду MAX для него не работает.
